# Daily risk pack  (ID: RP-001)

| Field | Value |
|---|---|
| Version | 1.0.0 |
| Owner | Market Risk Reporting |
| Approval status | Draft |
| Code | `novera.reporting.pack` |
| Last validated | 2026-09-14 |

## Content
Headline KPIs (VaR by three methods, ES, 10-day VaR, liquidity-adjusted VaR, worst stress,
P&L, breaches, data quality, backtest zone), VaR by asset class and desk, backtest, stress,
limits in breach or warning, open breaches, P&L explain by desk, data-quality findings,
concentration, liquidity, risk flags, DV01 ladder, positions. Every page carries the run
id, snapshot ids, model versions and config hash.

## Formats
HTML (self-contained), PDF (rendered from the HTML by headless Chromium when Playwright is
installed, skipped otherwise), Excel (one sheet per table). Generated by `novera report`,
the API (`POST /runs/{id}/risk-pack`) and the Risk pack page.

## Rule
Nothing is recomputed in the pack; every table is read from the stored run.
